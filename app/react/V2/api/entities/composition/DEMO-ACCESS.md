# 🚀 Entity Composition Demo Access

## 📍 **How to Access the Demo**

The unified entity composition solution is now available as a live demo in the running Uwazi application.

### **URL Access**
Navigate to: **`/settings/entity-composition`**

### **Prerequisites**
- You must be logged in as an **admin** user
- The application must be running in development mode

### **Troubleshooting**

#### **If the demo doesn't load:**
- Ensure you're logged in as an admin
- Check the browser console for errors
- Verify the application is running in development mode

#### **If composition fails:**
- Check the mock API client logs in the console
- Verify the entity IDs are valid
- Ensure the user context is properly set

#### **If performance metrics are missing:**
- The demo uses simulated metrics
- In a real application, these would be actual measurements
- Check the browser's performance tab for real metrics
